# Security

Please avoid posting credentials, personal diagnostics or private hardware identifiers in public issues. For a suspected vulnerability, contact the maintainer through the GitHub profile and arrange a private reporting channel before sharing sensitive details.

The host runs elevated and optionally creates a logon task. It does not silently install drivers. Download separate drivers only from official sources. Do not weaken Windows security protections to bypass a driver error. Release hashes detect accidental changes; they are not a code-signing certificate. The alpha binary is not Authenticode-signed.
